# S3 Navigator

Плагин-панель для Far Manager 3: просмотр и скачивание файлов из S3-совместимых хранилищ (AWS S3, MinIO, Yandex Object Storage и любых других с тем же API).

English version: [README.en.md](README.en.md).

## Возможности

- Несколько профилей подключения: endpoint, ключи, регион и бакет по умолчанию у каждого
- Список бакетов и листинг объектов, виртуальные папки (CommonPrefixes)
- Скачивание отдельных файлов и целых деревьев папок с сохранением структуры подкаталогов
- Диалог конфликта при существующем локальном файле: перезаписать / пропустить / переименовать / дописать / отменить, с запоминанием выбора для всех
- Прогресс скачивания: полосы по файлу и общий итог в диалоге плюс индикатор в таскбаре
- Редактирование, дублирование, переименование и удаление профилей прямо из панели
- Настройки в JSON внутри профиля Far, старый формат конфига мигрируется автоматически
- Подпись запросов AWS Signature V4 (SigV4)
- HEAD-запросы, чтобы показать размер и контрольную сумму (CRC32 или MD5/ETag) до скачивания
- Отладочный лог в файл внутри профиля Far при сборке debug

## Клавиши

В режиме списка профилей:

| Клавиша | Действие |
|---|---|
| F4 | Редактировать профиль |
| Shift+F4 | Создать новый профиль |
| Shift+F5 | Дублировать профиль |
| Shift+F6 | Переименовать профиль |
| F8 / Delete | Удалить профиль |
| Shift+F9 | Сохранить настройки вручную |

## Сборка

Проект написан на D и собирается через [DUB](https://dub.pm/) с пакетом
`far3api` (версия 3.0.6116). Сторонние зависимости: `curl`, `shell32`, `ole32`.

```
dub build              # debug
dub build -b release   # release, бинарник попадает в bin/rls/
```

Бинарник — `far_s3.dll`. Кладём его в каталог плагинов Far Manager, например:
`%FARPROFILE%\Plugins\S3Navigator\`.

Перезапускаем Far Manager, открываем меню плагинов (F11) или меню дисков
(Alt+F1/Alt+F2) — пункт «S3 Navigator».

## Настройки

Настройки лежат здесь:
`%LOCALAPPDATA%\Far Manager\Profile\PluginsData\far-s3-navigator\settings.json`
и содержат массив профилей:

```json
{
  "profiles": [
    {
      "name": "My S3",
      "endpoint": "https://s3.example.com",
      "bucket": "my-bucket",
      "accessKeyId": "AKIA...",
      "secretKey": "...",
      "region": "us-east-1"
    }
  ]
}
```

Если поле `bucket` пусто — при входе в профиль показываются все бакеты.

## Отладка

Debug-сборка пишет лог сюда:
`%LOCALAPPDATA%\Far Manager\Profile\PluginsData\far-s3-navigator\s3navigator.log`
